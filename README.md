# Situs Untuk Ega

Situs statis ini dapat dipublikasikan menggunakan GitHub Pages.

## Publikasikan

1. Unggah seluruh isi folder ini ke repository GitHub publik, dengan `index.html` di root repository dan branch utama bernama `main`.
2. Di repository GitHub, buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
5. Setelah publikasi selesai, URL situs akan muncul di **Settings → Pages**.

Foto, audio, dan video pada folder `photos` dan root repository ikut tersedia di situs.
